# Habit Streak Widget

Track daily habits and build streaks.

## Features
- Tap to complete habits
- Track streaks automatically
- Beautiful widget showing today's habits
- Free: 3 habits
- Pro ($0.99): Unlimited habits, stats, calendar, reminders
